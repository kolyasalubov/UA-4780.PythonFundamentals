# **Bulletin Board Project**
#### ***Overview***
This project is a simple bulletin board application where users can create, view, edit, and delete announcements.

#### Features
**Home Page:** Displays all announcements.

**Add Announcement:** Form for creating a new announcement (/add).
**
Edit Announcement:** Form for modifying an existing announcement (/edit/<id>).

**Delete Announcement:** Removes an announcement (/delete/<id>).

**Jinja2 Templates:** Use of blocks, loops, and data insertion for dynamic pages.

**SQLAlchemy Integration:** Work with an SQLite database without writing raw SQL.
